Coding Agent Lab - Windows x64
================================

This is an unsigned learning-project release for 64-bit Windows.

The runner prefers a trusted PowerShell 7 in Program Files\PowerShell\7 or a
7-* sibling and falls back to Windows PowerShell 5.1 in the Windows system
directory when needed. A WindowsApps alias is not trusted as a PowerShell 7
candidate. Standard Windows 11 therefore does not require a separate
PowerShell 7 installation.

1. Extract the ZIP to a stable directory outside the repository/workspace you
   want the agent to edit, for example:
   %LOCALAPPDATA%\Programs\CodingAgentLab\<version>
2. Set DEEPSEEK_API_KEY in the parent process environment if you want to use the
   real DeepSeek model. The executable intentionally does not load workspace
   .env files.
3. Change to the target repository and run the full path to cagent.exe.

Keep these files together:
  cagent.exe
  cagent-windows-sandbox-runner.exe

Examples:
  C:\path\to\cagent.exe --help
  C:\path\to\cagent.exe --version
  C:\path\to\cagent.exe "analyze this repository"
  C:\path\to\cagent.exe --resume <session-id>

The native runner is rejected if it is located inside the writable workspace.
The executable and runner are not code-signed; verify the published SHA256 file
before running them.
