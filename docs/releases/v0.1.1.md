# Coding Agent Lab v0.1.1

这是首个完整发布到 GitHub Release 的 Windows x64 学习版，重点补齐权限模型、原生执行边界和 Session 持久化稳定性。

## 主要变化

- 新增 `/permissions` 三档预设：逐次询问、受限自动批准与显式 Full Access。
- Full Access 使用宿主用户的文件、环境变量和网络权限，同时继续由原生 Job Object 管理进程树、超时与取消。
- 权限模式切换会先停止当前 Session 的活跃 Sub-agent，避免旧授权跨策略继续生效。
- Windows Sandbox 协议升级到 v2；Bun 缓存硬链接在受限模式下可读但不可写，不再阻止无关 Shell 命令启动。
- Memory Extraction 不再让 Stub 模型生成伪提取结果，并对返回协议及持久化摘要进行严格校验。
- Session Index 改为每个 Session 只保留最新条目，通过同目录临时文件原子替换，并自动压缩旧版重复记录。
- 修复 Release workflow 未向打包后 Sandbox E2E 传递原生 runner 路径的问题。

## 安装

下载 `coding-agent-lab-v0.1.1-windows-x64.zip` 及同名 `.sha256`，校验后解压到目标 workspace 之外的稳定目录。保持以下两个文件位于同一目录：

- `cagent.exe`
- `cagent-windows-sandbox-runner.exe`

在目标仓库目录中，通过 `cagent.exe` 的完整路径启动。真实 DeepSeek 模型需要在父进程环境中设置 `DEEPSEEK_API_KEY`；发行 EXE 不加载 workspace `.env`。

## 已知边界

- 仅发布并验证 Windows x64；Ubuntu 用于 TypeScript 控制面、离线测试与 Demo。
- 二进制未做代码签名，Windows 可能显示 SmartScreen 提示。
- Windows 原生 Sandbox 只约束内置 Shell 的文件写入和进程生命周期，不隔离网络，也不是宿主机保密边界。
- Full Access 是显式危险模式，会继承当前宿主用户权限。

完整安全假设与残余风险见仓库中的 `README.md` 和 `native/windows-sandbox-runner/README.md`。
