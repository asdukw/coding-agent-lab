# Coding Agent Lab v0.1.0

首个 Windows x64 学习版发行物，重点展示 Coding Agent 控制面的完整工程链路，而不是 npm 包分发。

## 包含内容

- 独立 `cagent.exe`，运行时不依赖 Bun、npm 全局链接或 shebang。
- 同包原生 `cagent-windows-sandbox-runner.exe`，承载 Restricted Token、Capability ACL、Job Object 与有界 I/O。
- Agent Loop、Plan Mode、危险工具审批、Session 恢复、Memory、MCP 与 Sub-agent。
- `--help`、`--version`、`--resume` 正式命令行入口。
- ZIP 的 SHA256 校验文件。

## 安装

下载 `coding-agent-lab-v0.1.0-windows-x64.zip` 及同名 `.sha256`，校验后解压到目标 workspace 之外的稳定目录。保持两个 EXE 位于同一目录，再从希望操作的仓库目录调用 `cagent.exe`。

## 已知边界

- 仅验证 Windows x64；Ubuntu 只覆盖 TypeScript 控制面、离线测试与 Demo。
- 二进制未做代码签名，Windows 可能显示 SmartScreen 提示。
- 内置 `Shell` 需要 MSI/ZIP 方式安装在 `Program Files` 的 PowerShell 7；不支持 Microsoft Store WindowsApps 版本。
- Windows 原生 Sandbox 只覆盖内置 `Shell`；它不是 VM，也不提供网络或宿主机保密隔离。
- 真实模型当前使用 DeepSeek OpenAI-compatible API；发行 EXE 只读取父进程环境变量，不加载 workspace `.env`。

完整安全假设与残余风险见 [`docs/architecture.md`](../architecture.md) 和 [`native/windows-sandbox-runner/README.md`](../../native/windows-sandbox-runner/README.md)。
