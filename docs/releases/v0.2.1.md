# Coding Agent Lab v0.2.1

这个补丁版本将内置文件发现与内容搜索切换为 ripgrep，并把经过固定版本与 SHA-256 校验的 Windows x64 `rg.exe` 直接包含在发行包中。

## 主要变化

- `Glob` 使用 `rg --files --glob` 枚举文件，`Grep` 使用 `rg --json` 执行正则搜索。
- `Grep` 在调用 ripgrep 读取内容前保留原有路径权限过滤，受保护路径不会进入内容搜索参数。
- 大型文件集合会按 Windows 命令行长度与参数数量分批搜索，原有 `content`、`files_with_matches` 和 `count` 输出结构保持不变。
- Windows x64 发行包内置官方 ripgrep `15.2.0` 的 `rg.exe`，构建时校验固定 SHA-256，并包含 MIT 与 Unlicense 文本。
- 运行时优先解析 `cagent.exe` 同目录的 `rg.exe`；源码运行仍可使用 `PATH` 中的 `rg`。
- 移除不再需要的 npm `glob` 依赖及其传递依赖。

## 升级注意事项

下载 `coding-agent-lab-v0.2.1-windows-x64.zip` 及同名 `.sha256`，校验后完整解压到目标 workspace 之外的稳定目录。请保持以下三个文件位于同一目录：

- `cagent.exe`
- `cagent-windows-sandbox-runner.exe`
- `rg.exe`

本版本沿用 Windows Sandbox 协议 v3，但 CLI 与 runner 的版本仍需匹配。真实 DeepSeek 模型继续通过父进程环境变量读取 `DEEPSEEK_API_KEY`，发行 EXE 不加载 workspace `.env`。

## 已知边界

- 仅发布 Windows x64 发行物；其他平台从源码运行时需自行提供 `rg`。
- ripgrep 默认遵循 ignore 文件并跳过隐藏文件、目录与二进制文件。
- 二进制未做代码签名，Windows 可能显示 SmartScreen 提示。
- Windows 原生 Sandbox 只约束内置 Shell 的文件写入和进程生命周期，不隔离网络，也不是宿主机保密边界。

完整安全假设与残余风险见 [`docs/architecture.md`](../architecture.md) 和 [`native/windows-sandbox-runner/README.md`](../../native/windows-sandbox-runner/README.md)。
